## 二、第二章揭開的真相（只揭到這裡）

1. **那根手指在中州。**
   - 劍仙斬下的那一指落在中州腹地，化成一座白玉一樣的孤峰：玉指峰（暫名）。
   - 三千年來，它把靈氣滲進地底，中州因此靈脈縱橫，成了修真的中心。
   - 大衍皇朝的開國之君在峰下立都，叫天衍城；欽天監的觀星台就蓋在峰頂。
   - 中州人只說這座峰「形如一指」，沒人想過它真的是一根手指。
   - 「大衍」取自「大道五十，天衍四九，人遁其一」：天定下四十九，總有一個逃得掉。那一個，就是你。
2. **命簿是那隻手寫的。**
   - 斷了一指以後，那隻手寫不出新的命，只能照舊的抄。
   - 這三千年的氣運之子演的都是同一套戲：退婚、三年之約、宗門大比、秘境奪寶。
   - 這就是「命簿腐朽」：壞的不是幾頁，是整本書只剩重抄。
3. **欽天監讀得到命簿。**
   - 玄微當年教皇朝的人看星星（殘頁・星），他們學會的是看命簿。
   - 天驕榜就是欽天監從命簿上抄下來的氣運之子名單，所以上面永遠不會有你。
4. **血月是撕頁。**
   - 欽天監相信，命簿是從東荒那一頁爛起來的：
     - 縫在東荒頭上；
     - 東荒有兩段字跡疊在一起的人、劍仙的傳人，還有「命外之人」的傳說。
   - 他們認為不撕掉這一頁，整本書都會爛。
   - 玉指峰在血月的夜裡會滲出朱墨，他們就用它把整頁劃掉。
   - 被劃到的地方，人死、獸狂、地裂，靈氣倒流回玉指峰。中州的世家早就在等這一波靈脈。
   - 上一世的天元 3022 年，東荒那一頁被劃掉了，蘇清瑤就死在那一夜。
5. **你是朱筆劃不到的人。**
   - 命簿上沒有你，朱筆落在你身上，找不到字就散了。
   - 這一世多了一個你，那一夜擋得住。但你只有一個人，只能在一個地方。
6. **整本書都在爛。**
   - 那一夜命簿攤在天上，所有人都看見了：爛的不只東荒那一頁。
   - 欽天監撕了三千年的頁，也救不了這本書。

**留給第三章以後的：**
- 那隻手的主人是誰：天道、看門的，還是天外的什麼。
- 天門後面有什麼；天河接不接得回去。
- 江底的老前輩是誰。
- 玄微的第九頁。
- 元嬰與無盡海。

### 三種處境的玩家都要照顧到

築基的早晚因人而異。GDD 寫過，一般資質在普通地方要閉關二十五年以上才能煉氣圓滿；就算找到好地方、好丹藥，不少人築基、渡江時也已經過了 3022 年。所以第二章要讓三種處境的人都有完整的一章：

| 處境 | 他經歷的第二章 |
|---|---|
| 早到：3022 年前渡江 | 1.0 到 1.2 的事都趕得上；血月那一夜，自己選在哪裡 |
| 晚到：3022 年後才渡江 | 血月那一夜他還在東荒，守的是家。中州的事以「之後」的樣子等他：生死約戰成了傳聞，沈家的信已經遲了。玉指峰的結局一樣走得到 |
| 一直沒渡江 | 血月照樣來，東荒那一夜照樣打。結局等他哪天過江 |

這就是建議把結局放在血月之後的原因（第十三節第 2 點）。如果血月就是最後一幕，晚到的人還沒見過中州，第二章就先結束了。

### 血月那天怎麼算

- 固定在天元 3022 年七月十五：中元節，月圓。七月也是天河斷掉的月份。
- 閉關中的人，系統提前三天叫醒你：「叮——天象異常。本系統建議宿主：出關。」閉關本來就有被打斷的機制，這裡沿用。
- 版本落差的處理：
  - 1.3 以前的版本走到這一天，只有異象：紅月、天上的縫亮了一下，那一筆沒有落下。
  - 存檔第一次載入 1.3 時已經過了這一天的，血月順延到下一個七月十五。
  - 故事裡說得通：命簿在爛，連朱筆都遲了；也可以讀成「有你在，那一筆停住了」。

## 七、主線

### 第一幕・渡江（1.0）

1. **白鶴渡**
   - 第一次渡江，照舊先看第一章的結局畫面。看完，船靠上鶴歸渡，不再把你送回去。
   - 已經看過結局的舊存檔，老船夫直接載你過江。
2. **臨江城**
   - 系統：「叮——偵測到大量氣運之子。本系統建議宿主：低調。」
   - 你是東荒來的散修，沒有宗門、沒有家世；城裡的洞府按月收租。
3. **天驕榜**
   - 榜樓上掛著中州的天驕，欽天監的星官每個月改一次。
   - 你打贏榜上的人，榜上也不會有你。星官翻遍了冊子：「查無此人。」
4. **重逢與傳聞**：重逢蘇清瑤（交好或結仇）；在天劍宗山門遇到葉孤寒；聽到林塵的傳聞。
5. **舊觀星台**：殘頁・星，玄微在中州的那幾十年。
6. **王二的第一封信。**
7. **1.0 的結尾**：欽天監注意到了。天驕榜最下面，多了一個空白的位置。

### 第二幕・靈脈之爭（1.1）

1. **龍脊嶺**
   - 謝家和上官家爭靈脈。你可以選邊、兩邊都做，或趁亂撿便宜。
   - 誰贏，關係到血月那一夜誰肯借樓船。
2. **沈家敗落與那封信**（3019 年）：信交到你手上，過不過江、什麼時候送，由你。
3. **生死約戰**（3020 年秋，天劍宗山門外）
   - 謝家的局：林塵會被下毒，切磋會變成死鬥。
   - 信送到了，林塵看穿這個局；沒送到，看你那天在場做了什麼。
   - 結果寫進葉孤寒的「三戰」。有人死，命簿就改了。
4. **天劍宗的祖訓**
   - 讀過劍冢碑、帶著古劍殘片的人，見得到祖師堂。
   - 在劍池重鑄古劍，學會「斷天」，也就是孤峰上的那一劍。
5. **百草谷**：孫掌櫃的師門；葛雲蘅認得《葛氏丹經》。
6. **本命法寶**：見第八節。

### 第三幕・天衍城（1.2）

1. 官道關開了，可以去天衍城。
2. 蘇清瑤帶你看欽天監的命簿抄本：天驕榜就是從這裡抄出來的。
3. 玉指峰為什麼封山；皇陵裡，開國之君與玄微的事。
4. 小血月越來越多：欽天監在試筆。
5. 查到真相：3022 年七月十五，他們要撕掉東荒那一頁。
6. **準備**：誰去哪裡、誰要撤走（見第八節「血月名冊」）。

### 第四幕・血月（1.3）

**那一夜，你在哪裡就在哪裡打。**

- **東荒**（青石鎮、清虛觀、狐仙廟）
  - 紅了眼的獸從山裡下來。
  - 朱筆一筆一筆落下，落點先紅一圈。你站進去，那一筆落在你身上，找不到字就散了。
  - 但每擋一筆，你身上就沾一點墨。墨沾多了，命簿會開始寫你的名字：那一夜剩下的時間，朱筆也傷得到你。所以不能每一筆都擋，要挑。
  - 學了「斷天」的人，可以在半空把筆斬斷，不沾墨。
- **白鶴渡**
  - 江底的老前輩醒了。
  - 跟老翁有交情的，它替你吞掉飛過江面的朱筆。
- **天衍城・玉指峰**
  - 欽天監在峰頂下筆。你闖上去，筆就停得早。
  - 但東荒那邊沒有你，只有你託付過的人。
- **別的地方**
  - 你看見紅月和天上的那本書。
  - 一頁紙從書裡飄下來找到你：殘頁・月。不管你那一夜在哪裡都拿得到。

**天亮以後**：誰活著、誰的命簿改了、天上的縫還在不在。結果照「血月名冊」與那一夜的經過結算，用傳聞與見聞頁交代。

**上玉指峰了結**（天亮之後，什麼時候去都可以）
- 對手：衛長庚，與守峰的神獸（暫定獬豸）。
- 那根手指怎麼辦，四個選擇，各有代價：
  1. **毀了它**：再也沒有朱筆。但中州的靈脈從此一年一年變弱，皇朝會動搖。
  2. **封回去，交給天劍宗**：照舊，換一個看守。
  3. **帶走**：你握著那支筆。那隻手，總有一天會來找它。
  4. **交給皇朝**：得到榮華；下一次撕頁，不知道輪到哪裡。
- 殘頁・指在峰頂。

**第二章結局畫面**：照第一章的寫法。你是誰、在中州幾年；每個人後來怎麼樣；命簿上的每一行，是照寫的，還是被你改了（墨跡還是濕的）；系統幾級、殘頁幾頁。最後一行留給第三章，例如：「天外，那隻少了一根手指的手，停了下來。」

## 八、玩法與系統

### 散修在大城

- **洞府按月租**：城裡貴、靈氣好；鬼市便宜、靈氣差；也可以在野外自己找。欠租會被趕出來，閉關到一半也一樣。
- **鬼市**：夜裡才開；賣來路不明的東西，要靠鑑定，也有假貨；中州的懸賞多半從這裡接。
- **傳送陣**：兩座城之間收費傳送。

### 天驕榜

- 每月更新。榜上的人可以挑戰，他們是有名有姓、會說話的對手。
- 你打贏了，榜上也不會有你；打贏的次數夠多，榜的最下面會多出一個空白的位置。

### 客卿，不拜師

中州的宗門只收你當客卿：用得到寶庫、任務與論劍，但不必離開青雲宗，也不必拜師，保住「一介散修」。

### 本命法寶（金丹以後）

- 選一件兵器或法器當本命，拿材料養它。
- 它跟著你升級，養到一定程度會多一招。
- 第一章的東西也能當本命：古劍殘片重鑄後的劍、玄甲衣、寒玉佩……

### 結丹在中州

（整個修煉體系的方向，包括金丹的成色與之後的境界，見 [修煉體系.md](修煉體系.md)。）

結丹的助力照北原的做法加在現有的突破表上（凝金丹、靈脈結、星官手記之外）：
- 龍脊嶺的靈眼；
- 天劍宗的結丹洞；
- 拍賣行的凝金丹。

### 新的招式與心法（約略）

- **斷天**：孤峰上的那一劍。古劍重鑄後才學得到；很長的一道斬擊，能把空中的東西斬斷。
- **欽天監的星術**：星落（落地的範圍招）、移星（換位）。
- **本命法寶的那一招**。
- **心法**：兩到三門（天劍宗、欽天監、百草谷各一）。

  - 第二章用自己的表與索引，或像 0.25 一樣用旗標判斷。
- **血月的日子**：算一次，記在 `s.vars`，含順延規則。閉關用現成的 `interrupt` 提前叫醒。
- **地形一次定案**：地圖一在 1.0 定案，之後只加地點與事件，藥草的編號不會變。
- **存檔只做加法**
  - 新人物、新旗標由 `migrate` 補預設值。
  - 新地圖的位置與霧，照 `w.away` 的現成做法存。
  - 不改任何舊欄位的意思。
- **結局畫面**：`ending.js` 改成能傳章節。
- **命簿殘影**：`fateLine` 隨第二章更新：寫好的一筆兌現了、被改了，或那個人走了，都要換寫法。
- **大城的效能**
  - 建築、人潮、天上的劍光都設上限，遠的簡化。
  - 每一版都在手機解析度量幀率，照 0.24 的量法。
- **測試**
  - 渡江來回與存讀檔。
  - 血月的日子，含舊存檔的順延。
  - 第二章時間點的索引，舊存檔不重跑、不跳過。
  - 新地點都在走得到的地上、離藥草夠遠；東荒的藥草編號不變。
  - 命簿的每一行。

## 十一、風險與對策

| 風險 | 對策 |
|---|---|
| 份量是第一章的好幾倍 | 拆成四版。每版先做完、測過、發布，再做下一版 |

| 劇情前後矛盾 | 第一節那張表當驗收清單；測試鎖住命簿的每一行；寫之前先對 GDD 的劇透區 |
| 大城在手機上卡 | 建築、人潮、劍光都設上限；每版量幀率；先做臨江城，天衍城等第一座城量過再做 |
| 舊存檔出問題 | 只做加法；新的時間點不插進舊表；地形一次定案；每版跑舊存檔的遷移測試 |

| 宮城、樓閣和水墨風格不搭 | 先在美術風格指南裡定規矩（朱紅只用在柱子與印章），再動手 |

## 十三、要你決定的事

### 1. 血月的日子：固定，還是等你？

- **固定**（建議）：天元 3022 年七月十五，世界不等人。
  - 和第一章一致：蘇清瑤照時間走、松鶴照時間坐化、王二照時間老去。
  - 蘇清瑤的玉簡、第一章結局畫面的最後一行都寫了這個年份。
  - 晚到的人照樣有完整的第二章（第三節）。
- **等你**：渡江後幾年才來。這樣蘇清瑤的警告就不準了，「世界是活的」也打了折扣。

### 2. 血月是結局，還是轉折？

- **轉折**（建議）：血月是第二章最大的一場戲；結局在之後的玉指峰，什麼時候去都可以。這樣早到、晚到、沒渡江的人，都走得到同一個結局。
- **結局**：照升級計畫第九節原本的寫法，血月那一夜就是第二章的最後一幕。晚到的人還沒見過中州，第二章就先結束了。

### 3. 真相揭到哪裡？

- **建議**：
  - 揭開：手指在中州（玉指峰）、命簿是那隻手寫的、血月是撕頁、整本命簿都在爛。
  - 留給第三章：手的主人、天門後面、江底的老前輩、玄微的第九頁。
- 想留更多懸念，可以把「血月是欽天監撕頁」改成第二章只揭一半：知道是欽天監下的筆，不知道為什麼。

### 4. 拆成幾版？

- **四版**（建議）：1.0 渡江、1.1 靈脈之爭、1.2 天衍城、1.3 血月。每版的份量和南嶺、西漠、北原差不多。
- **三版**：把 1.2 和 1.3 合在一起。好處是真相和那一夜一起發布；壞處是那一版會是目前最大的一版。
