# 《一介散修》美術風格指南

> Phase 5（0.24）美術升級的依據。之後新增的地圖、建築、人物、妖獸、特效都照這份規則畫。遊戲裡的畫面全部是程式繪製：2D 地圖用畫布筆刷，3D 世界用 WebGL 著色器，人物、妖獸與道具是用同一套筆刷畫在立牌上。畫好的圖（手繪或 AI 生成）可以從素材槽接入，規則見最後一節。

---

## 一、總則

1. **水墨淡彩**：紙色打底、墨色定形、淡彩上色。寧可留白，不要塞滿；不追求寫實光影。
2. **手機上一眼看得清**：橫拿手機、離眼睛 30 公分，玩家、敵人、可互動的東西都要一眼分得出來。好看但看不清，就是不合格。
3. **一個強調色**：朱紅只用在要你注意的地方（目標圈、危險預警、主要按鈕、印章）。其他顏色都要比朱紅安靜。
4. **四張地圖各有自己的顏色和天氣，但筆法一致**：同一支筆，畫不同的地方。
5. **每改完一類就量幀率**：在測試機（無顯示卡的軟體繪圖）上和改之前比，不得明顯變慢；「低畫質」要能關掉新加的細節。

## 二、色彩系統

| 用途 | 顏色 | 說明 |
| --- | --- | --- |
| 紙（春夏秋冬） | `#e9e5d4`、`#e3e3d0`、`#ece0c8`、`#efefec` | 一切的底色。雲霧、未探索的地方回到紙色。 |
| 墨 | 畫面 `rgb(36,33,30)`、介面 `#23201b` | 輪廓、皴紋、文字。從不使用純黑。 |
| 朱紅 | 介面 `#a8322a`（`--red`） | 唯一的強調色。 |
| 五行 | 金 `#a5832a`、木 `#3d7a3c`、水 `#2f5f8f`、火 `#b4452c`、土 `#8a6538` | 招式、靈根、符的顏色（介面的 `--el`）。 |
| 淡彩 | 各地形的底色（`worldview.js` 的 `GROUND`） | 都是灰過的顏色，彩度低。 |

- **東荒**：溫帶的青綠與赭黃，四季分明（春嫩綠、夏青綠、秋赭黃、冬灰白）。
- **南嶺**：濕潤的藍綠，水氣重，遠處偏青灰；瘴氣帶一點黃綠。
- **西漠**：小米色的沙、偏紅的砂岩（3D 岩石染成 `rock: [1.24, 1.02, 0.78]`），空氣偏暖、偏亮。
- **北原**：白雪、冰藍，岩石偏冷灰（`rock: [0.92, 0.97, 1.08]`），一年到頭都是冬天的樣子。

## 三、光源、明暗與描邊

- **3D 的光**：太陽從觀者的右後方（東南）斜照，朝向鏡頭的山壁是亮面。明暗交界是柔的（`paintLight`），沒有硬邊的投影；物件底下用淡淡的墨暈代替影子。
- **2D 的光**：陰影落在右下。
- **墨往低處積**：窪地、崖腳、屋簷下、樹叢底比周圍深一點；山脊、崖頂、高處淡一點（像是隔了更多空氣）。
- **描邊**：只描外輪廓與結構線（崖頂的邊、屋脊、人物外形），不描每一個面。線條要有粗細、斷續，不要等寬的電腦線。
- **遠近**：越遠越淡、越偏霧色（`haze`）；遠處的樹比近處的樹淡、細節少。

## 四、地形

- **地面**：三層墨暈疊起來，打破「一整片平塗」：
  1. 一格一格的底色互相滲開（已有）；
  2. 幾十步大小的濃淡塊（新增，在著色器裡）；
  3. 細細的紙紋與草點（新增，近處才有，遠處淡掉以免閃爍）。
- **道路**：中間走出來的淡色路面，兩側斷續的深色邊；官道兩條車轍，小徑是點狀的足跡，石板路有石縫。
- **山岩懸崖**：
  - 山壁用直立的「斧劈皴」：順著坡向下的長筆，濃淡不一。
  - 西漠的砂岩加橫向的層理。
  - **崖頂描一道墨線**，崖腳積墨。
  - 北原的崖頂積雪，崖面露出冷灰的石頭。
- **雪地與冰**：雪地不是純白，要有淡淡的藍灰陰影；冰面要有裂紋與反光。

## 五、樹木與草

- 每種樹至少三個明度：暗部、中間、亮部。樹冠不是一團實心的墨。
- **遠樹淡、近樹濃**；林子深處偏冷、偏暗。
- **你走進樹林時，擋在你前面的樹冠變淡**，讓你看得見自己（玩家永遠看得見）。
- 草叢、蘆葦、竹子用短筆觸；隨風輕輕擺動。

## 六、水

- 河、湖：岸邊一道墨線，靠岸淺、中央深；水面的波紋隨時間緩動；有天空的淡淡倒影。
- 瀑布與深潭：白色水沫、霧氣。
- 冰面（北原）：見第四節。

## 七、建築形制

| 地方 | 形制 |
| --- | --- |
| 東荒 | 灰瓦白牆、木柱；鎮子是街屋，宗門有牌坊、台階、大殿與飛簷。 |
| 南嶺 | **吊腳樓**：竹木架高、茅草或樹皮頂、木梯，寨子沿坡而建（Phase 5 新畫）。 |
| 西漠 | 夯土牆、平頂或圓頂、寺院有塔；古城殘牆與半埋的石雕。 |
| 北原 | 石牆、厚木、屋頂積雪；寒鐵堡是方形的堡壘。 |
| 中州（1.0） | **白石、石灰牆、深青灰的瓦**，柱子少量朱紅；臨江城是有城門樓的方城、石板街、榜樓（塔）、樓船碼頭；天劍宗是劍山上的石台與牌坊。配色由地圖帶（`BUILD_PALETTE`），形制沿用同一套 3D 建築，不另畫一套。 |
| 地宮與洞穴 | 要有「頂」的感覺：四周暗下來，頂上有星圖或岩縫的微光（Phase 5 新畫）。 |

### 中州（1.0）的其他畫面

- **天上的劍光**：城與宗門之間的航道上一直有人御劍飛過。白天是帶藍暈的白色劍光（淺色地面上要看得到，所以有藍暈），夜裡是暖色的燈與一點尾光。只是天空的樣子，不能互動；數量少（同時十來道），遠的不畫。
- **人潮**：看榜的人（白天）、碼頭的腳夫（白天）、鬼市（夜裡）各有一群人；街上的行人比東荒的鎮子多。
- **妖獸換皮**：中州的妖獸沿用現有造型，換上中州的顏色（`scenery.js` 的 `tinted`）：蘆蕩青蟒是更青的蟒、蒼梧木精是更綠的木魅、蒼梧猿是黑毛的雪猿（扔的是石頭不是冰）、雲夢蛟是水青色的沙蛟；守台石獸是石色的狻猊（狼形加鬃毛），眼裡是星光。眼睛的顏色保留，不跟著換。
- **1.1 的對手**：靈脈蜈是縮小的蠱母、甲殼換成藍水晶；謝家的人穿深藍金邊的號衣（護衛拿刀，老祖白鬚、拿劍）；劍池劍靈是新畫的——一個淡光做的人形，身邊繞著六把小劍。

- 屋頂是建築最大的面，用最清楚的明暗：向陽一面淺，背陽一面深，屋脊描墨。
- 門口與可進去的地方要看得出來（門洞深色、門前有路）。

## 八、人物與妖獸

- **人物**：略帶 Q 版而不幼稚，立牌高約為寬的 2 倍；墨色外輪廓，衣服用低彩度的顏色。有名有姓的人物各有一個認得出的顏色或配件。
- **妖獸**：外形先求剪影好認（狼、蛇、熊、蠍、豹各有一眼看得出的輪廓），再加細節。首領比同類大、配色更重。
- **淺色的妖獸在雪地上**：加深色外輪廓與腳下的影子，不能和雪混在一起。
- **動作**：待機有呼吸，走路有起伏，出手有預備動作，受擊要往後仰、閃白。

## 九、特效

- **五行配色**：金（白金）、木（青綠）、水（藍）、火（朱橙）、土（赭黃），與介面的五行色同一組；冰（淡青白）、雷（紫白）。
- **形狀先於顏色**：劍氣是細長的弧，法術是圓，範圍技是地上的圈；預警一律用朱紅、由淡變濃。
- **快而短**：命中特效 0.2～0.4 秒，不能擋住下一招的預警。
- **技能圖示**：每一招一個水墨圖示（src/art/icons.js），染上五行色；戰鬥鍵上名字疊在圖示上（紙色光暈），收藏庫裡框上五行色。

## 十、可讀性規則（不能為了好看而犧牲）

1. 玩家永遠看得見：被建築或樹擋住時有淡淡的剪影，走進樹林時前面的樹冠變淡。
2. 敵人與地面要有明暗對比；預警圈永遠在最上層。
3. 可以互動的東西有標籤，靠近時有提示。
4. 文字不疊在人物身上。

## 十一、效能預算

- 地面著色器是畫面上最大的一塊，新增的細節要算得起：只用幾次雜訊、不額外讀貼圖；**低畫質**時關掉細紋。
- 立牌（人物、妖獸、會動的東西）一個畫面最多 128 張；佈景（樹、石）用實例繪製，一張圖集。
- 每一類改完都要拍同樣的場景、量一次幀率，記錄在 A7 的回報裡。

## 十二、素材槽（畫好的圖）

素材槽的用法見 [assets/README.md](../assets/README.md)。手繪或 AI 生成的圖要符合：

- **視角**：從南方斜上往北看下來，大約俯角 45～58°；不能是正側面或正上方。
- **光**：從右後方（東南）來，與 3D 世界一致。
- **透明背景**、腳在圖底中央、高約為寬的 2 倍（人物）。
- **風格**：水墨淡彩、墨色輪廓、低彩度；同一批要有同一個參考圖，免得每張不一樣。
- **動作**：要會動的（走、出手、受擊），要給切好的連續格；給不了的，維持程式繪製。
- **不能用一整張場景圖代替可行走的世界**。
- 單頁版（claude.ai 上的連結）不讀素材資料夾，只能內嵌少量的圖。最適合的是技能圖示、道具圖示、事件插圖與人物頭像。
