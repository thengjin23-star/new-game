# 《一介散修》玩法說明

> 試玩版 0.20・第一章「東荒」。寫給玩家，也寫給一起做這個遊戲的人：遊戲現在有什麼、怎麼玩。設計與數值的細節在 [GDD.md](GDD.md)。

## 一句話

天道為眾生寫好了命，只有你，不在命簿上。

你是東荒邊陲一個資質平庸的凡人，從一次墜崖開始，帶著一個不太可靠的「問道輔助系統」，在一個會自己運轉的修仙世界裡走、看、打、修煉，盡量活久一點。

## 一輪在做什麼

1. **走出去**：在一整片相連的大地圖上自由行走，撥開雲霧，找地方、找人、找東西。
2. **遇上事**：劇情、路上的現場、野獸與劫修、機緣。選擇會被記住，有些幾個月、幾年後才回來找你。
3. **帶回來**：靈石、靈草、材料、丹藥、功法、法器，還有人情與名聲。
4. **閉關**：找靈氣好的地方坐下，用真實的時間換修為（關掉遊戲也會繼續）。
5. **突破**：修為滿了就衝擊下一個境界。壽元變長、走得更快、能飛、打得過更強的東西，去更遠的地方。
6. 壽元一直在走。死了可以輪迴，系統記得你。

## 開始一生

- **入世**：取名字、選性別、選出身（農家子、獵戶之子、落第書生、藥鋪學徒、街頭孤兒，各有長短）。天命四項（根骨、悟性、心性、機緣）和靈根是天定的，可以再看三次，但別抱太大希望——你不是天驕。
- **開場**：為了給母親採藥上青石山，失足墜崖，系統綁定。在清虛觀醒來，老道士松鶴傳你《長春功》。第一次閉關「引氣入體」之後，就完全自由了。

## 操作：橫著玩

手機直拿的時候，畫面會自己轉成橫的，把手機橫過來玩就好（螢幕方向鎖定、或在不會轉向的 App 裡也一樣）。

| 位置 | 是什麼 |
|---|---|
| 左下 | 搖桿。按住拖動就走；畫面其他空地按住拖動也行 |
| 畫面上 | 點地面：自己走過去（會繞路，學了輕功還會跳）；點人或東西：走過去互動；兩指捏合：拉近拉遠 |
| 右下大鈕 | 眼前能做的事：拜訪、查看、採摘、打聽…… |
| 大鈕旁 | 「坐」歇息、搜尋、閉關；「術」法術與符；「飛」起飛（飛著時變「落」） |
| 左上 | 名字、境界、靈石、日期時辰、修為、氣血、靈力；下面一排是所在的地方（點它看說明）、探索度、季節、天氣、天象、身上的狀態 |
| 右上 | 行囊、修煉、見聞、系統；小地圖（點開是大地圖） |

左上地點那一排下面有一行「目標」，寫著接下來可以做什麼（只是提示），點它看怎麼做。第一次碰到某顆鈕時，旁邊會冒出一句指點。

**戰鬥時**右下變成戰鬥鈕，像 MOBA：大鈕普攻，圍著它的是目前這組的招式（一組四招），左下方綠色的是閃避，再外圈是符和藥，最上面寫著「壹」「貳」的小鈕換另一組。

**鍵盤**：WASD 或方向鍵行走、E 互動、M 地圖、F 術、R 飛；戰鬥 J 普攻、1 2 3 4 四招（朝滑鼠方向，按住看範圍、放開施放）、Tab 換組、空白鍵或 Shift 閃避、F 燒符、Q 吃藥。

## 探索

- **地方**：青石鎮、清虛觀、青石山、鎮南田野、東荒野地、落霞坊市、黑風林、靈溪谷、古戰場遺跡、青雲宗、狐仙廟、鏡湖、白鶴渡；還有只有飛（或跳）才上得去的孤鶴峰、江心洲、斷劍峰。
- **雲霧**：沒去過的地方蓋著雲，走過才畫出來；聽說過的地名寫在雲上、打個問號。每個地方都有探索度。
- **藏著的東西**：斷碑、石縫、野地裡的箭袋、田埂下的瓦罐……走近了才發現。境界越高、用「神識」一掃，找到的越多。
- **現場**：路上看到頭上有「！」「？」的人或東西，就是有事正在發生，走過去看。
- **人**：有名有姓的人站在他們該在的地方，路人可以搭話；茶館、坊市路口可以打聽傳聞。
- **時間**：走路就是過日子，有白天、黃昏、夜裡。有些人只在夜裡出現，有些東西只在月光下發亮。
- **「坐」**：四處搜尋（兩個時辰）、歇一會兒、歇到黃昏／入夜／天明、下雨下雪時等它停、閉關。

## 修煉

| 境界 | 小境界 | 怎麼往上 | 壽元 |
|---|---|---|---|
| 凡人 | — | 「引氣入體」 | 70 |
| 煉氣 | 一到九層 | 修為滿了自動晉升 | 120 |
| 築基 | 初期、中期、後期、圓滿 | 煉氣圓滿後衝擊瓶頸 | 220 |
| 金丹 | 初期、中期、後期、圓滿 | 築基圓滿後結丹；結成時看成色 | 520 |
| 元嬰 | 初期、中期、後期、圓滿 | 金丹圓滿後結嬰；機率過了還要渡心魔劫 | 1020 |
| 化神 | 初期、中期、後期、圓滿 | 元嬰圓滿後化神；機率過了還要渡雷劫 | 2500 |

化神之後還有煉虛、合體、大乘、渡劫，但三千年來沒有人過得了化神（「修煉 → 修為」下面的「境界一覽」寫著）。

- **修為**：閉關時長得最快；平常走動、探索也會慢慢長（約閉關的兩成）。
- **閉關**：「修煉」頁選一個月、半年、一年、三年或十年。就在你站的地方閉關，靈氣越濃越快（荒郊野外可能被打擾）。要花真實時間（遊戲一天約三秒，一年約十八分鐘），關掉遊戲也會繼續；隨時可以提前出關。閉關時世界照常運轉——秘境開了又關，故人老去。元嬰以後入定更深：閉關一天在現實裡只要一秒，化神不到一秒。
- **速度**：基礎 × 靈根 × 功法 × 靈氣 × 心境 × 傷勢 × 增益 × 天時，每一項在修煉頁都看得到；金丹期還乘上金丹的成色。元嬰中期以後，靈氣不夠濃的地方修得慢（修煉頁會寫「靈氣不足」）。
- **突破築基**：成功率看靈根（五靈根 3%、四靈根 6%、三靈根 12%、雙靈根 25%），再加上築基丹（每顆 +25%，最多兩顆）、感悟、心境。失敗會掉修為、受傷、心境下降，丹藥也沒了。
- **金丹的成色**：結丹成功時，看你結得多穩（機率、凝金丹、地方、心境，還有運氣），分下品、中品、上品、極品。成色越好，金丹期修得越快（下品九成、極品一成二五），結嬰也越容易。
- **心魔劫**（結嬰）：機率過了，還要跟心魔打一場——它長得和你一模一樣，只是一身墨色，比你強一些，嘴裡說的是你這一生虧欠過的事。打贏才結嬰；輸了修為、心境都退，折壽十年。找一片空曠的地方。
- **雷劫**（化神）：機率過了，劫雲壓頂、天色轉成雷雨，落雷一波一波打在你身邊一整片地方（命簿上沒有你，雷鎖不住你），落點先紅一圈。撐到劫雲散了才化神；輸了重傷，折壽三十年，帶傷渡劫是找死。化神這一關，感悟最多算到四成（悟道）。
- **元嬰出竅**：元嬰以後，肉身被毀時元嬰能逃出來，重塑肉身：瀕死很久、掉三成修為、少活幾十年，一年內修煉只有六成。六十年才能再來一次；壽元盡了則救不了。
- **壽元**：剩不到三十年會警示。突破，才能延壽。
- **功法**：「修煉 → 功法」可以改修別的功法；身法、術法也在這頁。

## 戰鬥（即時）

- **怎麼打起來**：野獸、劫修看見你會撲上來；事件裡選了標著「戰」的選項；秘境、大比、獸潮。
- **右手**：
  - 大鈕普攻，按住連打（第三下最重）；點一下妖獸也會上前打。
  - 招式（一組四招）：點一下自動瞄準；按住拖動自己瞄準，放開施放，拖回按鈕上取消。
  - 換組：外圈最上面的小鈕（或 Tab）換另一組；冷卻跟著招式走，換組不會重置。施放到一半、戰鬥試煉裡不能換。
  - 閃避：短距離一閃，途中打不中你。
  - 符、藥：戰鬥符三息一張；藥吃身上最好的療傷藥（中毒先吃解毒丹），八息一顆。
- **流派與配招**：見下一節「技能」。

  | 流派 | 招式（五行） |
  |---|---|
  | 劍修 | 劍氣（金）、劍影（金）；築基後：飛劍（金，飛出去再飛回來）、劍陣（金，劍影繞身） |
  | 法修 | 火球（火）、狐火（火）、回春術（木）、藤縛（木，纏住一片）、玄冰刺（水，凍慢）、掌心雷（木，天雷落在瞄準的地方） |
  | 體修 | 掃腿（土）、衝撞（土）、金剛（金） |
  | 通用 | 靈力外放、護體（學了玄水真經變玄水盾，水） |
  | 法器 | 照妖、金鐘（金） |
- **五行相剋**：金剋木、木剋土、土剋水、水剋火、火剋金。招式剋得住對手，傷得重（綠色數字，鈕下有「剋」字）；被剋，傷得輕（灰色數字）。妖獸的五行寫在名字後面、圖鑑裡：狼與蛇屬木、靈溪蟒與玄龜屬水、鐵背熊與山魈屬土、赤炎妖虎與狐屬火、骷髏將軍屬金。
- **相生連招**：木生火、火生土、土生金、金生水、水生木。四息之內接上「上一招所生」的那一招，威力更強，連到第三招更強；能接的鈕會亮。例如：藤縛（木）→ 火球（火）→ 掃腿（土）。和自己靈根同屬性的招式也順手些。
- **看預警**：地上亮起紅色的範圍，就是要打過來的地方，看到就閃。
- **打擊感（0.20）**：打中的瞬間畫面會頓一下、震一下，分層次——普攻很輕，連打的第三下（重擊）重一些、數字也大，暴擊最重（數字前寫著「暴擊」、金色的光），擊倒對手時牠身上的墨會濺開，擊倒最後一個時整個畫面放慢一瞬，首領倒下時更長。被打中時畫面邊緣會紅（傷得越重越紅），護體擋下時護罩上會泛起一圈漣漪，護罩破了會碎開。只有世界的畫面會動，按鈕永遠不動。
- **招式打中的樣子**：每種招式打中都不一樣——劍氣留下一道斬痕、身上一道白亮的切口；火球炸開、餘燼往上飄；掌心雷劈下來、電光在身上亂竄；玄冰刺打碎成冰屑；狐火是藍色的火星；藤縛與木系是飛散的葉子；土系是揚起的塵；沒有五行的普攻濺出墨點。護體施放時，護罩會從外面一圈圈收攏到身上。
- **對手被打中**：會往後一縮、停一下腳（首領不會）；剛縮過不會馬上又縮，所以不能一直壓著打。連打的第三下或暴擊，能打斷牠正在蓄的招（打斷之後要隔一陣子才能再打斷）。笨重的鐵背熊、山魈比較不容易被打得縮手。
- **對手的變化**：鐵背熊、山賊、山魈血少時會發狠（更快、更痛）；武人血少時會退開半步、換架勢，出完招就跳開；修士、執法弟子、武人、狐影看得見你的劍氣與法術，常常一閃就躲開——對付牠們，落點範圍的法術、近身的招式比較好用。狼群倒下一隻，其餘的會長嚎發狂；倒下過半就散。
- **戰鬥手感設定**：系統頁「戰鬥手感」——畫面震動（強、標準、弱、關）、命中停頓（開、關）。手機設定了「減少動態效果」時，震動預設為關。
- **首領**：名字和血條在畫面上方，會換階段、會狂暴，有範圍技、毒與火、纏繞、召喚、瞬移。
- **境界壓制**：高你一個大境界的對手非常危險。
- **逃跑**：跑得夠遠、躲進密林、進城，對手就會放棄。
- **輸了**：切磋點到為止；真打輸了是重傷，甚至身死（系統的替死能擋一次）。
- **練手**：系統頁的「戰鬥試煉」會幻化一頭妖狼陪你練，幻影傷不了你。

## 技能（0.19）

「學會多少招」和「帶幾招上陣」是兩件事。打開「修煉 → 技能」：

- **快捷欄**：一組四格，可以配兩組（築基後三組）。先點一格、再點下面的招式放進去（或先點招式、再點格子）；同一招已經在這組裡，就和那格對調；✕ 清空一格。「戰鬥時先用這組」決定打起來先拿哪一組。一組沒動過就由系統自動配：學會新招會自己換上，第二組放第一組沒放的招式。
- **技能收藏庫**：所有招式和心法都在這裡，學會的、還沒學會的都看得到，沒學會的寫著怎麼學（境界、功法、兵器、根骨、法器）。可以搜尋（名字、流派、五行、效果）、照流派、類型（攻擊、範圍、控制、身法、護身、療傷、劍陣）、學會與否篩選，照靈力、冷卻、名稱排序。
- **熟練度**：招式在真正的戰鬥裡用得越多越熟——初學、小成（15 次）、精通（50）、大成（120）、圓滿（300）。每升一級威力多一成的一半、冷卻少一點，有的招式到某一級還會多出效果：靈力外放大成後穿透、劍氣變寬、火球燒得更久（圓滿時炸得更開）、護體撐得更久、回春術更快、玄冰刺凍得更久、衝撞撞暈更久、掌心雷範圍更大（圓滿時暈更久）。戰鬥試煉不算。
- **心法**：不必施放，修持著就一直生效。引氣入體後能修持一門，築基兩門、金丹三門、元嬰四門、化神五門。

  | 心法 | 怎麼得到 | 效果 |
  |---|---|---|
  | 長春護體 | 學會長春功 | 戰鬥中每秒回 0.4% 氣血；平時回得快 25% |
  | 劍心 | 學會青元劍訣或小周天劍陣 | 劍修招式傷害 +12%、暴擊 +3% |
  | 火候 | 學會烈焰訣或狐火術 | 火屬招式傷害 +15%、靈力 −10% |
  | 青木生生 | 學會青木訣或松鶴吐納術 | 療傷多三成、木屬招式冷卻 −15% |
  | 玄水凝神 | 學會玄水真經 | 所有招式靈力 −12% |
  | 銅皮鐵骨 | 根骨 7 以上 | 受到的傷害 −8% |
  | 踏雲身 | 學會踏雲步 | 閃避冷卻 −25%、腳程 +6% |
  | 靈台清明 | 築基 | 所有招式冷卻 −10% |
  | 五行流轉 | 築基，且學過青木訣、玄水真經或烈焰訣 | 相生連招的加成再 +10% |
  | 厚土載物 | 學會厚土訣（南嶺水簾洞） | 受到的傷害 −6%、土屬招式傷害 +12% |

- **掌心雷**：青石山的雷擊木。雷雨天去那裡，能從落雷裡悟出「掌心雷法」；不是雷雨天就得靠悟性。天雷直接落在你瞄準的地方，一片都打到、打得對手一愣。

## 氣血、靈力與傷勢

- 左上常駐兩條：紅的是氣血，青的是靈力（引氣入體之後才有）。
- 傷帶在身上：受了傷，氣血上限只剩七成半（輕傷）、五成（重傷）或三成（瀕死），血條上看得見那道限。
- 走著路會慢慢回；「坐」裡歇息每個時辰回兩成氣血、三成半靈力；閉關出來全滿。止血草、血參、回春丹回氣血，凝氣草回靈力。

## 裝備與買賣

- 身上四格：兵器、衣袍、佩飾、法器。行囊最上面的「身上」看得到穿戴，物品點「裝備」「卸下」。
- 加成：氣血、靈力、減傷、回復、暴擊、腳程、神識、抗火。法器戴著，還多一招可以帶上陣。
- 店：青石鎮藥鋪（賣靈草）、落霞坊市的聚寶閣、百煉坊（兵器、衣袍，帶材料來還能打造狼皮襖、蟒鱗甲……）、符籙攤（符、照妖鏡、青玉佩、功法書）。坊市的名聲越好越便宜。
- 未知的東西要鑑定（系統二級，或花十靈石）。

## 法術與符籙

- 「術」鈕（有法術或野外能燒的符時才出現）：
  - 神識：往四周一掃，藏著的東西現形、雲霧散開、草叢裡伏著的蛇被標出來。
  - 回春術：回三成氣血並解毒。
  - 斂息術：九十息內野獸要走到跟前才發覺你。
- 野外燒的符：神行符（走得快一半）、斂息符、驅邪符、歸元符（一陣風送你回最近去過的城鎮）、避瘴符（過黑風林的瘴氣）、御風符（飛）。
- 戰鬥裡燒的符：火符、金光符、驅邪符。在行囊裡按「隨身」挑一種帶著。

## 修仙百藝：洞府、煉丹、畫符、精煉

- **洞府**：找到青石山腹的洞府以後，走到石縫前查看，「收拾洞府」就是你的了。能閉關，也有現成的丹爐和硯台。在洞府裡可以布「聚靈陣」（三重，要靈石、妖獸內丹、雷擊木、玄陰石、鏡湖明珠），布滿三重是東荒靈氣最濃的地方。
- **煉丹**：身上有青銅丹爐（百草堂賣）或人在洞府，「坐」→「煉丹」。挑丹方、放藥材，然後控火：爐火在文火與武火之間來回擺，亮的那段是火候，到了就按「收火」。三次都準是上品（多一顆），全不準會炸爐。聚氣丹、療傷丹、解毒丹、清心丹隨時能煉；築基丹要先找到《築基丹方》（秘境裡、或青雲宗寶庫）。
- **畫符**：身上有狼毫符筆（符籙攤賣）或人在洞府，「坐」→「畫符」。只畫得出身上有過的符。照著淡紅的符紋描，筆一落硃砂就開始乾；描得準、沒有多餘的筆畫，一張紙畫出兩道。少一筆、亂塗都會廢。每張用一張符紙、一份硃砂（符籙攤有賣）。
- **精煉**：在百煉坊，身上穿戴的東西可以拿給老韓再煉，最多 +3，每級多一成五。要靈石和妖獸內丹（+3 還要雷擊木）。

## 輕功與飛行

- **輕功**（身法，學了就一直有用）：走得快、難走的地拖不住你；往溪、矮牆、斷崖推過去，停一下就躍過去（花一點靈力）。
  - 輕身術：符籙攤買書。
  - 踏雲步：孤鶴峰的石壁上悟得，跳得更遠更高。
- **飛**：

  | 飛法 | 誰能用 | 怎麼得到 | 特點 |
  |---|---|---|---|
  | 御風符 | 誰都能用，凡人也行 | 符籙攤、江心洲的破船、宗門寶庫 | 不耗靈力，六十息就落下，飛不高 |
  | 青木飛梭 | 引氣入體之後 | 符籙攤、宗門寶庫 | 耗靈力，矮山小嶺飛得過 |
  | 御劍 | 築基，手上拿著劍 | 青鋼劍（宗門寶庫）、寒鐵劍（百煉坊） | 最快，什麼山都飛得過 |

  - 青雲宗內門弟子可以用貢獻換《御劍訣》：學了之後**煉氣七層**起就能御劍，只是靈力耗得多一半。
  - 飛著的時候點地面就直直飛過去；地上的野獸夠不著你，路上也不會遇事；靈力一直在耗，耗盡了就近落下。
  - 飛不過去的：青雲宗的護山大陣（不是弟子不行）、大江那頭（中州，第二章）、世界邊緣的群山。大江上空別待太久，江裡睡著一個很老的東西。
- **空中的地方**：孤鶴峰（鶴巢、踏雲步、可閉關）、江心洲（釣魚的老翁、破船）、斷劍峰（只有御劍上得去；劍痕可參悟、可閉關）。

## 南嶺（0.21）

- **怎麼去**：鎮南田野一直往南，到山隘的界碑那裡「翻過山隘」。適合煉氣以上；凡人也過得去，只是會被瘴氣熏得半死，翻一趟要大半天。回來從南嶺的嶺口翻回東荒。打開大地圖，最下面的「往別處去」列著出口。每張地圖各自記得你看過哪裡；存檔會記得你在哪張圖上。
- **瘴氣**：瘴林、毒沼、萬蠱谷裡有紫色的霧。走進去會問你怎麼過：
  - 避瘴丹（青竹寨百藥鋪 30 靈石，或自己煉）：服下三天之內瘴氣近不了身，最省事。
  - 解毒丹、避瘴符各一，或提 15 點靈力封住口鼻。
  - 什麼都沒有就閉氣衝出去（看根骨，失敗昏兩天、受傷）。
  - 做完寨子的主線，阿蘿會在你血裡種下避瘴蠱，從此南嶺的瘴氣再也近不了身。
- **青竹寨**：寨老岩伯、阿蘿的百藥鋪（避瘴丹、解毒丹、療傷丹、聚氣丹、避瘴符；帶毒蛛絲來能織蛛絲軟甲，帶蠱母甲來能綴金蠱甲；不精煉）、寨井、銅鼓坪（打聽）、山神龕（歇腳）。
- **主線「寨井發苦」**：看看寨井 → 找岩伯 → 問阿蘿 → 萬蠱谷除蠱母 → 燒蠱巢 → 回寨子。左上的「目標」會一步一步提醒你。蠱母是目前最難的野外首領：煉氣後期、帶足丹藥再去；蠱蟲和蠱母屬金，火的招式剋牠們。
- **支線**：阿山的弟弟困在瘴林的白絲洞（火符能把毒蛛逼開）；救回來之後，去碧潭的瀑布看看。嶺口的韓三在瘴林丟了包袱。
- **妖獸**：瘴林毒蛛（被網黏住就閃避掙脫）、毒沼巨蟾（舌頭很長，別站在牠正前方）、蠱蟲群（站著不動會被叮死）、首領毒蟾王與蠱母。南嶺的對手很多帶毒：帶解毒丹（戰鬥中按「藥」會先吃它），或穿抗毒的甲。
- **修煉**：瀑布後的水簾洞是南嶺最好的閉關處（靈氣 1.7）；洞裡石壁上的《厚土訣》（土）會教你「地刺」，還有心法「厚土載物」。
- **歸元符**在南嶺會送你回青竹寨（只送到同一張地圖上的城鎮）。

## 西漠（0.22）

- **怎麼去**：古戰場一直往西，進山到「西風口」的山口「出西風口」。適合築基；沒築基也出得去，只是路上會渴得半死、烈日與沙暴傷得更快，一趟要一天一夜。回來從落日關東邊的山口翻回東荒。築基之後，系統的推演會告訴你西風口在哪。
- **烈日與沙暴**：西漠不下雨，該下雨的時候颳沙暴；晴天正午前後是烈日。在空曠的沙地上頂著走，走久了先會提醒你（「該找個陰涼地方，或者喝口水了」），再走下去就會出事，要選怎麼辦：
  - 烈日：喝口水（水囊）、服冰心丹（三天不怕烈日）、嚼兩顆沙棘果、提 20 靈力把暑氣壓下去、找背陰處躺到日頭偏西（耽擱時辰）、咬牙硬撐（看根骨，失敗會昏倒、傷到氣血上限）。
  - 沙暴：蹲下等它過去（耽擱時辰）、放神識摸著走（15 靈力）、頂著風闖（看根骨）。沙暴裡走得慢、看不遠、飛不起來。
  - 月泉、落日關、沙陀寺的峽谷、地宮裡曬不著也吹不到，走進去就慢慢緩過來。
  - 一勞永逸：寒玉佩（康家駝隊）或蛟鱗甲不怕烈日；定風珠（沙蛟身上的）讓沙暴繞開你。
- **流沙**：流沙區裡有陷人的沙窩。陷進去別亂掙：提氣拔身（10 靈力）最穩，平躺著挪看悟性，拚命掙看根骨。
- **月泉**：西漠唯一的綠洲集市。月泉驛（月娘：水囊、冰心丹、療傷丹、解毒丹、聚氣丹、歸元符；大堂可以打聽古城、沙陀寺、流沙、禿鷲寨）；康家駝隊（寒玉佩、青玉佩、清心丹、御風符；帶三片沙蛟鱗來，老皮匠縫蛟鱗甲）；泉邊可以歇腳。
- **故事**（左上的「目標」會一步一步提醒你）：
  - 康駝頭請你去黑戈壁的禿鷲寨討個說法。禿鷲刀很快，帶足丹藥；打贏之後饒不饒他，你決定。之後駝隊的貨打八五折。
  - 了空請你去沙陀寺看看他的師父。白天去只看得到坐著的僧人；**夜裡**才見得到枯禪。乾屍和枯禪是陰物：兵刃打不太進去，火與佛門的招式好用。
  - 宋夫子抄了三十年的碑。沉沙古城的五塊碑你讀得懂——讀完五塊，去城北的星門看看。
  - 落日關的老秦託你一件事：回東荒時，夜裡在西風口點起那座烽燧。
- **妖獸**：沙蠍躲在沙裡（走近了才冒出來）、沙狼成群、沙盜撒沙迷眼（被迷了腳下會慢）、夜裡沙陀寺的乾屍、古城的石傀（慢但很重）；首領禿鷲、枯禪、沙蛟（流沙深處，西漠最難的對手：血少了會把四周變成流沙池）、星門的石翁仲。
- **修煉**：地宮靈氣 1.8，是西漠最好的閉關處；望河臺（只有飛得上去）1.5。沙陀寺藏經窟的《大日心經》（火）會教你「大日輪」：周身一圈金色的日輪，把四周的對手震住、推開，對陰物特別疼。地宮裡的《星官手記》帶在身上，衝擊金丹的成功率 +8%。
- **歸元符**在西漠會送你回月泉。

## 北原（0.23）

- **怎麼去**：斷劍峰北邊，從斷石門往北爬上雁回嶺，到山口「翻過雁回嶺」，一趟一整天。適合築基後期到金丹；**築基以下也過得去**，只是會凍傷（凡人可能凍死），到了那邊冷得更快。回來從雪嶺口的山口翻回東荒。
- **嚴寒**：北原一年到頭是冬天。在露天的地方走久了，寒氣鑽進骨頭（夜裡、下雪、暴風雪更快）：先提醒你（「該找個地方烤烤火了」），再走下去就要選怎麼辦：燒刀子、暖身丹（三天不怕冷）、提 20 靈力把寒氣逼出去、找背風處蜷著（耽擱時辰）、咬牙硬走（看根骨，失敗會凍傷）。
  - 暴風雪：挖個雪洞等它過去、放神識摸路（15 靈力）、頂著風雪闖（看根骨）。暴風雪裡看不遠、走得慢。
  - 寒鐵堡、礦坑、白狼部的營火邊、靈脈裂谷裡不冷。
  - 狼皮裘（寒鐵堡的雜貨、鐵匠鋪，或阿蘭給你的）擋得住冷，暴風雪只擋一半；修火屬功法的冷得少，學了《寒魄訣》冷得更少；金丹寒暑不侵。
- **薄冰與雪崩**：北冥冰面上顏色發黑的是薄冰，踩上去會裂（輕功點冰而過最穩）；雪山與斷雲崖的雪坡會崩（往橫裡跑，或躲到大石頭後面；會御劍就飛起來）。
- **寒鐵堡**：霍堡主的堡主府、酒館（打聽北冥、白狼部、雪山、裂谷、不周山）、鐵匠鋪（寒鐵劍；帶材料來打狼皮裘、白狼王裘、冰蠶衣、寒鐵甲）、雜貨（燒刀子、暖身丹、狼皮裘）、火炕（歇腳）。
- **故事**（左上的「目標」會一步一步提醒你）：
  - 霍堡主說礦坑的深巷少了三個人，半夜有女人在唱歌。撬開深巷的木板，冰蠶母在盡頭——被冰絲凍住了腳就閃避掙脫。
  - 北冥的冰叟一輩子想看冰底下那條魚一眼。夜裡到冰心趴著看，或築基之後放神識往下探。
  - 靈脈裂谷的寒衣說，冰麟喜歡天鏡峰頂冰鏡縫裡的雪蓮。帶三朵去，牠會讓開；也可以拔劍——牠是北原最強的妖獸。走法不同，寒衣給你的也不同。
  - 白狼部的阿蘭，阿爹三年前往冰原東邊追白狼王，沒回來。
  - 不周山頂（只有飛得上去）的那道門底下，有一頁殘頁。
- **妖獸**：冰原狼成群（被咬中會凍僵一下）、雪豹伏在雪裡、礦坑的冰蠶吐冰絲、雪猿扔冰石、夜裡北冥冰上的雪魄；首領白狼王、冰蠶母、雪猿王、冰麟。都比西漠的強；築基初期以前進來，最好會閃、會跑。
- **修煉**：靈脈結靈氣 2.4（目前最濃），結丹在這裡衝擊加一成；還沒築基就在這裡閉關會傷經脈。《寒魄訣》（水）會教你「冰魄寒獄」：一掌按地，冰刺把一圈的對手凍僵。
- **歸元符**在北原會送你回寒鐵堡。

## 地利與結丹（0.23）

- 每張地圖寫著適合的境界（地圖頁右上），但不擋路：早去也行，要自己扛得住。
- **地利**：南嶺屬木、西漠屬火、北原屬水。在那裡修同屬的功法，修煉快一成五；靈根相合，快半成（修煉頁的算式裡寫著「地利」）。
- **結丹**（築基圓滿衝擊金丹）：凝金丹每顆加一成五，最多兩顆（丹方在寒衣那裡，靈髓為主藥）；在北原的靈脈結上衝擊再加一成；寒衣護法再加半成；西漠的《星官手記》帶在身上加八分。這些也會讓金丹的成色更好（見「修煉」）。

## 天時

- **天氣**：晴、陰、雨、雷雨、霧、雪。雨雪走得慢；雨霧看得近（野獸看你也是）；雨裡火弱；雷雨天飛在天上會被雷劈。西漠不下雨也不起霧，換成沙暴與烈日（見上）。每個存檔的天氣是固定的。
- **天象**：
  - 月圓（每月十五）：修煉快一成五，夜裡陰物更躁動。
  - 靈潮（每年三月、九月初十到十二）：修煉快五成，三天前有傳聞。
  - 血月（第六年起偶爾的十五）：野獸紅了眼。

## 青雲宗

- **入門**：天元 3014 年九月開山收徒（之後每十年一次），到青雲宗山門前測靈根：四、五靈根做雜役，三靈根入外門，雙靈根入內門。也可以轉身繼續做散修。
- **身分**：雜役 → 外門 → 內門 → 真傳，在任務堂看累計貢獻和修為晉升。
- **貢獻**：任務堂的差事（每七天換一批）、宗門雜務、大比。
- **寶庫**：用貢獻換丹藥、御風符、《輕身術》、青玉佩、青鋼劍、青木飛梭；內門起換得到《御劍訣》和築基丹。
- **月例**：每月初領靈石（內門、真傳還有聚氣丹）。
- **宗門大比**：每年六月初一到初十，三場切磋，連勝三場就是當年魁首。

## 第一章的終點

- **白鶴渡**：築基之後，老船夫肯載你過江了。渡過大江，第一章「東荒」就完了；築基後左上的「目標」會指向那裡。
- 渡江之前，東荒的幾條線會各自收尾（大約在天元 3016 年前後）：林塵去了中州，心裡有怨的話會先來把話說清楚；蘇清瑤也要走，交情夠的話她會在落霞坊市等你道別，結了仇的，走之前要和你算一算；松鶴道人的最後幾年，看你做過什麼。
- 系統到五級會想起自己的名字；江心洲的老漁夫，替你收著一頁殘頁。
- 上船時，交情夠的人會到渡口送你。上船後是這一章的結局畫面：你這一世走到哪裡，林塵、蘇清瑤、松鶴道人、王二（還有遇過的胡三娘）各自怎麼樣了，系統想起了什麼。
- （1.0）看完結局按「踏上中州」，船就靠上對岸的鶴歸渡，第二章「中州」開始。之後白鶴渡「過江」、鶴歸渡「回東荒」隨時來回（約四個時辰）；回東荒的船不問境界。在 1.0 以前看過結局的存檔，到白鶴渡就能直接過江。
- 還沒築基：老船夫不載，下游劉家的貨船肯（十塊靈石、心性檢定）。過得去就到中州（第一章也算完）；過不去，船在江心翻了，受重傷被沖回白鶴渡。

## 中州・臨江一帶（1.0「渡江」）

適合築基初期到金丹。大江在西邊，鶴歸渡在西南，臨江城在中間；北面是舊觀星台、蒼梧林，東北是天劍宗，往東是官道關（往天衍城的路，戒嚴中），東南是雲夢大澤，南面是千畝靈田與百草谷。

- **臨江城**：城上禁空——在城上飛太久，城頭先吹哨，再派巡城衛把你攔下來，可以認罰、動手或跑。城裡不能隨地閉關。
- **租洞府**：城裡的洞府行（靈氣 1.9，一個月 60 靈石）、鬼市破棚子後頭（1.45，一個月 12）；按月、半年、一年租。租期內才能在那裡閉關，到期就變回街上，閉關到一半也一樣。
- **天驕榜**：榜樓前的擂台，榜上第一百、五十、十名誰來挑戰都得接。打贏了，星官翻遍冊子也找不到你：「查無此人」。
- **懸賞堂**與聲望「臨江城」：中州自己的懸賞；聲望高了城裡的東西打折。上官瑾的名帖在上官記百貨另打九折。
- **商店**：上官記百貨、天工坊（青鋒劍、流雲法袍；拿蛟珠、星紋石做東西）、鬼市的夜攤（只在夜裡擺，賣築基丹，很貴）。
- **人**：蘇清瑤（臨江城的榜樓，3018 年起是欽天監的星官）、葉孤寒（天劍宗山門外）、鬼市的蕭七、上官商棧的上官瑾、謝家少主謝玄朗、茶樓的說書人；老船夫兩岸都在，過江一個月後替王二捎信來。
- **舊觀星台**：夜裡台邊的石獸會醒；打倒牠，石縫裡有一頁天機殘頁。
- **妖獸**：江堤蘆蕩的青蟒、蒼梧林的木精與黑猿、野地的劫修、夜裡從鬼市跟出來的刺客、雲夢大澤的蛟。
- **天上**：城與宗門之間，白天有劍光飛過，夜裡是一點一點的燈。
- **天元三千零二十二年七月十五**：子時月亮是紅的。1.3 以前只有異象，天上的那一筆不會落下來。

## 靈脈之爭（1.1）

中州的事照年份走；你不在場，就照它本來的樣子過去，變成傳聞。

- **林塵**：3016 年秋起是上官家的客卿，在上官商棧見得到他（照第一章的交情重逢）。
- **沈家敗落與那封信**（3019 年春）：謝家吃下沈家的生意。沈清歌託你把信帶過江交給林塵：「別喝謝家的東西。」沒人送，信遲三年才到。
- **生死約戰**（3020 年九月十五，天劍宗山門外）：謝家敬林塵的那杯茶下了軟筋散。
  - 信送到了，或你從鬼市的蕭七那裡聽說了軟筋散、告訴了他，他就不喝：三十招平手。
  - 那天在場：可以當眾喊破、擠上去撞翻茶杯；他喝了，可以跳上台擋在前面。
  - 什麼都沒做，照命簿：林塵輸了，葉孤寒沒有殺他。
  - 替謝家辦過事、收了謝玄朗的紙包的，還有一條讓林塵死在台上的路。
  - 結果寫進葉孤寒「三戰」的命簿。
- **龍脊嶺**：上官瑾請你把謝家的人趕出礦底；謝玄朗出四百靈石要你把上官家的礦工嚇下山。
  - 礦底有靈脈蜈、靈眼和靈髓。
  - 把謝家趕出去、或自己挖走靈髓，出關三百年的謝家老祖會來。
  - 兩邊都做也行，到 3021 年兩家對帳時會發現。
  - 沒人插手，3021 年判給謝家。
  - 上官家贏了，上官家的樓船欠你一回。
- **天劍宗**：
  - 掛名客卿，不拜師：金丹過守門師兄的劍；或讀過劍冢碑、帶著古劍殘片，由葉孤寒帶上山。
  - 客卿可以在天劍宗閉關（結丹洞）、逛寶庫（凝金丹）、每月上試劍崖論劍（贏三場學會天劍訣，心法「劍意」）。
  - 祖師堂的闕老說出祖訓：指，是那根手指。
  - 劍池的劍靈認了你，古劍殘片重鑄成斷天劍，學會「斷天」。
- **百草谷**：谷主葛雲蘅是葛老的妹妹。
  - 帶《葛氏丹經》給她看：傳你百草心經（心法「百草」、回春術），託你捎信給孫掌櫃。
  - 孫掌櫃收了信，再過幾年要自己關了回春堂，去百草谷。
- **衝擊金丹的助力**：龍脊靈眼（官司了結後）、龍脊靈髓（帶在身上）、天劍宗結丹洞（客卿）、寶庫的凝金丹。
- **本命法寶**（金丹以後）：
  - 行囊裡一件兵器或穿戴的東西可以定為本命，拿材料餵它。
  - 共五重，每一重它給的東西多一成；第三重學會「本命一擊」。
  - 換一件，原本的歸零。

## 死亡與輪迴

戰鬥、毒、心魔、壽元都可能讓你死去。真的死了，會看到這一世的生平，然後輪迴：系統等級、見聞、殘頁留下來，換一個新的身分重來。
