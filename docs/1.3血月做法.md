# 1.3「血月」做法與風險

> 狀態：**待你決定**（第七節）。決定以前，不動戰鬥核心，也不改存檔。
>
> 依據 [第二章規劃.md](第二章規劃.md)（定案）：
> - 第三節：三種處境；「血月那天怎麼算」——閉關提前叫醒、舊存檔順延到下一個七月十五，這兩件已經定了。
> - 第七節：第四幕「血月」與「上玉指峰了結」。
> - 第八節：血月名冊、系統六級。
> - 第九節：1.3 的範圍。
> - 第十二節：「不做新的戰鬥系統，只加招式、敵人與首領」。

## 〇、一頁看完

**1.3 有三段**
1. **那一夜**：天元 3022 年七月十五，戌時到寅時。你在哪裡，就在哪裡打。
2. **天亮以後**：照名冊、照那一夜的經過，算出每個人的下場。
3. **上玉指峰了結**：天亮以後什麼時候去都可以。對手是守峰神獸獬豸與衛長庚，打完是手指的四個選擇，最後是第二章的結局畫面。

**怎麼做**
- 不做新的戰鬥系統。那一夜沿用 0.26 化神雷劫的做法：天上一個打不到的東西（雷劫是劫雲，這裡是攤開的命簿與朱筆），隨時間一陣一陣地落下帶預警圈的攻擊。
- 和雷劫相反的地方：**朱筆要你站進去擋**，因為它找不到你的名字；擋一筆，沾一點墨。朱筆不會瞄準你，只落在東荒的人與地方上，所以要跑過去擋。

**最大的風險**
1. 要動到戰鬥核心裡「範圍攻擊落地」那一段（多兩個屬性）。所有範圍招式都經過那裡，改錯會連帶出問題。
2. 那一夜跨過存讀檔、閉關、舊存檔：現在的戰鬥一讀檔就算「逃走」，那一夜不能這樣。
3. 東荒有名有姓的人會真的死，蘇清瑤也可能死。這是規劃書的意思，但份量很重，要你確認。
4. 手機效能：紅月、落筆、成群的獸、隊友同時在場。
5. 這是目前份量最大的一版。

**要你決定的事**：八件，第七節，每件都附建議。

## 一、那一夜怎麼玩

### 1. 日子與節奏

- **日子**：天元 3022 年七月十五，戌時（19 時）月亮升起，到寅時（5 時）天亮。
- **舊存檔順延**（規劃書已定）：第一次載入 1.3 時已經過了這一天、又還沒打過那一夜的，順延到下一個七月十五。
  - 建議至少留 30 天準備，不夠就再延一年。
  - 故事上接 1.2 抄本上那一行「未竟。墨不足。」。
- **閉關**（規劃書已定）：前三天系統把你叫醒（現成的閉關中止機制）：「叮——天象異常。本系統建議宿主：出關。」
  - 不出關、坐過那一夜的，天亮以後照「你不在」結算，再告訴你發生了什麼。
- **三更三段**（建議）：
  - 一更：筆少，獸先下山。
  - 二更：筆密起來，朱墨凝成的東西爬出來。
  - 三更（子時前後）：天上的書整本攤開，最密的一段。
  - 每段即時打約一分半。段與段之間一張短卡（玄微或蘇清瑤的聲音、到目前為止落了幾筆），也是存檔點。

### 2. 你在哪裡，就在哪裡打

戌時那一刻你在哪裡，決定這一夜的樣子：

| 那一夜你在 | 這一夜是什麼 |
|---|---|
| 東荒：青石鎮、清虛觀、狐仙廟、落霞坊市一帶 | 主戰場。筆落在這裡的人和地方上，獸從山裡下來 |
| 東荒的別處（野地、山上） | 系統說筆往哪裡落：「朱筆往青石鎮去了」。趕過去，趕到以前落下的筆都不算你擋的 |
| 白鶴渡 | 筆從江那頭飛過來。江底的老前輩醒了：見過江心洲老翁的，它一口一口吞掉飛過江面的筆，你在渡口擋漏下來的 |
| 天衍城 | 闖上玉指峰：御階、皇城、欽天監、天梯，一路星衛與朱墨。越早到峰頂，筆停得越早，但東荒那邊只有你託付的人 |
| 別的地方（南嶺、西漠、北原、中州其他地方） | 看見紅月與天上的書，打不到。天亮以後照「你不在」結算 |

不管在哪裡，子時都有一頁紙從天上那本書裡飄下來找到你：**殘頁・月**。

### 3. 朱筆：落點、擋、沾墨、斬斷

- **落點**：地上先紅一圈，由淡變濃，約兩秒後一筆從天上落下來。
  - 系統六級的「朱筆預警」：紅圈早 0.6 秒出現，小地圖上也看得到遠處的落點。
- **只落在東荒的人和地方上**：家門口、清虛觀與狐仙廟的門口、鎮上的井與廟。**從來不對準你**，因為命簿上沒有你。
- **擋**：人站在圈裡，那一筆找不到字就散了。代價是沾一點墨（墨條 0 到 8）。
- **墨滿**：沾滿八點，「命簿開始寫你的名字」。那一夜剩下的時間，朱筆也傷得到你，而且很重。所以不能每一筆都擋，要挑。
- **斬斷**：學了斷天的人，斷天的劍氣穿過還沒落下的紅圈，那一筆在半空斷掉，不沾墨。斷天冷卻 14 秒，一段只用得了幾次。
- **沒擋住**：那一筆落在紙上。
  - 圈裡的隊友、鎮民受重傷；有一半的機會冒出一個朱墨傀。
  - 這個地方「被劃了一筆」，天亮以後算帳。

### 4. 紅了眼的獸與朱墨傀

- **紅了眼的獸**：當地現有的獸換成血月的樣子（紅眼，比平常兇），一波一波下山，像獸潮。強度跟著你的戰力走（照獸潮的算法），同時最多六到八隻。
- **朱墨傀**（新）：朱筆落地的地方爬出來的東西，慢、硬，走過的地上留一道墨。

### 5. 名冊在那一夜的樣子

- **撤到中州**：七月十三上官家的樓船從白鶴渡開走，人在中州，這一夜安全。
- **清虛觀、狐仙廟**：守的人擋得住獸，擋不住筆。筆落在觀上、廟上，躲在裡面的人一樣有危險。
  - 胡三娘的山「三百年沒讓那支筆碰過」：落在狐仙廟的筆減半。
- **託付的人**：林塵、天劍宗、蕭七的人那一夜在東荒。
  - 你也在場的話，他們當你的隊友打獸（現成的隊友機制）。
  - 他們在命簿上，朱筆傷得到他們，擋不了筆。
- **護身符**：替戴著的人擋掉落在他身上的第一筆。

### 6. 蘇清瑤

- 那一夜她在觀星台上。照規劃書：有沒有人陪她，決定她那兩段字跡最後剩下哪一段。
  - 你在峰頂，她那一段新的留下。
  - 沒人陪，剩下舊的那一段：「天元三千零二十二年七月十五，蘇清瑤，歿」。
- 建議加一條：名冊上可以託葉孤寒去陪她。但他去了觀星台，就不能帶天劍宗的人去東荒。
- 這兩件都要你決定（第七節第 3 件）。

### 7. 逃跑與放棄

- 照你的原則，那一夜任何時候都可以跑：離開戰場，筆照樣落，天亮以後照你在的時間算。
- 凡人、煉氣也站得進紅圈。擋筆靠的是「命簿上沒有你」，不靠境界。但獸會要命，要懂得躲。

## 二、天亮以後怎麼算

**落了幾筆**
- 每個東荒的地方，各算這一夜落在那裡的筆數。
- 先從總數扣掉：
  - 江底老前輩吞掉的；
  - 你闖上峰頂以後停掉的；
  - 你在場時擋下、斬斷的。

**每個人的下場**：活著、受傷、死了，由以下幾件決定：
- 那一夜他在哪裡（撤走、躲起來，或在家）；
- 誰守著他、有沒有護身符；
- 他那裡落了幾筆、你在不在。

**命簿**
- 死了的人寫「這一頁，被撕掉了」。
- 活下來、但跟命簿寫的不一樣的（例如撤到中州終老），墨跡是濕的（系統六級看得到）。

**之後看得到的**
- 傳聞、見聞的故事與人物頁、名冊頁的結果欄。
- **天上的縫**：落得少，縫合上了；落得多，縫還在，東荒的夜空留一道紅痕。被劃得重的地方，一年之內獸更兇。

## 三、上玉指峰了結

- **什麼時候**：天亮以後什麼時候去都可以。早到、晚到、沒渡江的人，都走得到這裡（規劃書第三節）。
- **對手**：
  - **守峰獬豸**（新首領）：一角的神獸，衝撞、角觸。
  - **衛長庚**（新首領）：欽天監的星術，星落（落地的範圍招）與移星（換位）。
  - 他是元嬰。建議：他的星術是照命簿瞄準的，一樣找不到你，只能砸地方；所以打得過，但要跑位。數值照 0.26 心魔劫的做法先模擬，再定強弱。
- **場地**：峰頂平台現在只有二十來格，兩個首領太擠。建議把峰頂放大一點，只改峰頂那一塊地形（第七節第 5 件）。
- **殘頁・指**：在峰頂。殘頁到 8／9，第九頁留給第三章。
- **手指怎麼處置，四個選擇**（後果的方向，數字可以再調）：

| 選擇 | 之後的世界 |
|---|---|
| 毀了它 | 再也沒有朱筆，小血月停了。中州兩張地圖的靈氣一年比一年弱，五年後到八成五。皇朝動搖（傳聞、禁軍變少）。天劍宗的祖訓了結 |
| 封回去，交給天劍宗 | 照舊，換一個看守。小血月停了。欽天監散了。天劍宗的交情上去，京城的聲望下來 |
| 帶走 | 你握著那支筆（一件信物）。小血月停了（墨在你身上）。留一個記號：「那隻手，總有一天會來找它」（給第三章） |
| 交給皇朝 | 榮華：靈石、名號、京城聲望到頂。小血月照舊會來，只是少一點。傳聞說下一頁不知道輪到哪裡（給第三章） |

- **衛長庚之後**：照你選的那一個走。例如毀了它，他留下來看著它碎；交給皇朝，他官復原職。
- **第二章結局畫面**：照第一章的寫法，每個人一行，不做過場動畫。
  - 你是誰、在中州幾年；
  - 每個人後來怎麼樣；
  - 命簿上的每一行是照寫的，還是被你改了；
  - 系統幾級、殘頁幾頁。
  - 最後一行留給第三章，跟著你的選擇換，例如「天外，那隻少了一根指頭的手，停了下來。」
  - 看完結局，世界照樣往前走。

## 六、風險與對策

| 風險 | 對策 |
|---|---|
| 改戰鬥核心，連累所有範圍招式 | 新屬性只掛在新招式上，舊招式走原路；這一段最先做、單獨測；長玩加跑雷劫、心魔劫、獸潮 |
| 那一夜中途讀檔、關掉遊戲 | 每一更是一個存檔點，讀檔從這一更重來，不算逃走；測試鎖住 |

| 舊存檔已經過了那一天 | 順延（規劃書已定），至少留 30 天；測試鎖住 |
| 東荒的人真的會死 | 這是規劃書的意思，份量重，要你確認（第七節第 2 件）。事前有蘇清瑤、系統、名冊的提醒 |
| 蘇清瑤可能死 | 要你確認（第七節第 3 件） |
| 手機效能 | 同時最多六到八隻獸、十個落點、四個隊友；紅月與落筆沿用雷劫的特效；在青石鎮量那一夜和平常的幀率 |
| 境界落差（凡人到金丹都可能在那一夜） | 擋筆不看境界；獸跟著戰力走；永遠逃得掉 |
| 衛長庚是元嬰，玩家多半金丹 | 他的星術找不到你，只能砸地方；先用模擬定強弱（同心魔劫的做法） |

| 份量最大的一版 | 拆成八步，每步提交、測過再走下一步；也可以分兩次發布（第七節第 7 件） |
| 峰頂太小 | 只放大峰頂那一塊（第七節第 5 件） |

## 七、要你決定的事

1. **那一夜的節奏**
   - **三更三段，每段約一分半，中間一張卡、也是存檔點（建議）**
   - 一整段約五分鐘
2. **東荒的人會不會真的死**
   - **會：照名冊和那一夜的經過算，事前有提醒（建議，照規劃書）**
   - 只有名冊上「不管」的人才可能死
   - 不會死，最多受重傷
3. **蘇清瑤**
   - **觀星台上沒人陪她，她就死（照規劃書）；另外加一條：可以託葉孤寒去陪她，但他就不能帶人去東荒（建議）**
   - 不加託付，只看你在不在峰頂
   - 她不會死，只是失去上一世的記憶
4. **墨沾滿**
   - **只影響那一夜（照規劃書），另外留一個記號給第三章（建議）**
   - 只影響那一夜，不留記號
5. **最終戰的場地**
   - **把玉指峰頂放大一點，只改峰頂那一塊（建議）**
   - 不改地形，改在欽天監的高台上打
6. **手指四個選擇的後果**
   - **照第三節那張表的方向（建議）**；數字做的時候會再寫給你
   - 你想改哪一個
7. **版本**
   - **一次發布 1.3（建議）**
   - 先發「那一夜＋天亮」，再發「玉指峰＋結局」：比較早玩得到，但中間那一版沒有結局
8. **舊存檔順延的通知期**
   - **至少 30 天（建議）**
   - 至少 15 天
   - 至少 90 天
