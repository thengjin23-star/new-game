# 即時戰鬥（Action Combat）：架構分析與改造方案

> 目標：把「探索 → 遭遇 → 切進戰鬥面板 → 回合制輪流出手」，改成「探索 → 發現敵人 → 就地即時開打 → 自由移動、瞄準、施法、閃避 → 打贏／逃走／倒下 → 繼續探索」。
> 一句話：像 MOBA 一樣即時移動與操作技能，但保留修真 RPG 的世界探索、角色成長與自由冒險。

本文件分成四部分：現況檢查、問題 A–H 的回答、新架構、分階段計畫。第一階段的即時戰鬥原型就照這份方案實作。

---

## 一、現況檢查

| # | 系統 | 目前怎麼做 | 主要檔案 |
|---|---|---|---|
| 1 | 戰鬥 | 回合制。依身法「充能」決定誰先出手，玩家選一個行動後，一次結算到下一個玩家回合，再把結果一拍一拍播給畫面。戰鬥期間 `s.pending` 存在，世界整個停住。 | `core/battle.js`、`art/fightplayer.js`、`world/arena.js` |
| 2 | 玩家移動 | 每幀 `step(s, dt, input)`：搖桿、WASD 或點地尋路；格子碰撞（半徑 12）、地形速度（樹林 0.75、密林 0.55…）、爬坡變慢、境界越高走越快。**走路會讓時間流逝**（375 單位＝1 時辰），並觸發雲霧、發現、區域事件、隨機遭遇。 | `world/explore.js`、`world/terrain.js` |
| 3 | 敵人 AI | `MOBS`：在領域內閒晃 → 聽見（狼嚎）→ 警戒「？」→ 追擊「！」→ **碰到你就開事件**。遠強於牠們就逃。牠們不會「攻擊」，只會「抓到你」。 | `world/explore.js`、`world/places.js` |
| 4 | 技能 | `SKILLS`（掃腿、靈力外放、青元劍氣、火球術、狐火…）與戰鬥物品。冷卻以「回合」計，目標是「點選對象」，沒有方向、距離、範圍。 | `core/battle.js` |
| 5 | HP／靈力 | 只存在於一場戰鬥裡，由戰力推算；平時只存「傷勢等級」（無傷／輕傷／重傷／瀕死）。 | `core/battle.js`、`core/cultivation.js` |
| 6 | 遭遇事件 | 事件資料＋現場導演。23 個戰力檢定選項帶 `fight` 規格，選了就進回合制戰鬥，勝負決定走哪個結局。 | `core/events.js`、`world/director.js`、`content/events/` |
| 7 | 世界地圖 | 一整片連續大世界：區域、格子碰撞、尋路、高度、雲霧。立體與平面兩種畫法共用同一份資料，以及 `worldToScreen`／`screenToWorld`。 | `world/geo.js`、`world/terrain.js`、`world/height.js` |
| 8 | 介面 | 每幀 `onFrame` → `E.step`。拖動畫面任意處＝搖桿，點擊＝走過去／互動，鍵盤 WASD/E/M。上方 HUD（姓名、境界、時辰、修為）、右下動作鈕、底部選單、事件卡圖層。戰鬥時是回合制面板（行動列、招式選單）。 | `ui/app.js`、`styles/main.css` |
| 9 | 狀態管理 | 存檔物件 `s`（玩家、世界、旗標、`pending`、`battle`）＋不存檔的「活狀態」`liveOf(s)`（路徑、野獸、路人、現場）。 | `core/state.js`、`core/save.js`、`world/explore.js` |
| 10 | 資料結構 | `FOES`（名稱、畫法、速度、形狀、技能、戰利品）、`MOBS`（地圖上的位置、數量、領域、速度、戰力）、`SKILLS`、`ITEMS`、事件。 | `content/`、`world/places.js` |

結論：**世界、移動、碰撞、畫面、資料都已經是「即時」的；只有戰鬥本身是回合制、而且被做成一個會讓世界暫停的「事件」。** 所以改造的重點是「戰鬥迴圈」和「戰鬥的入口」，不是整個遊戲。

## 二、A–H

### A. 哪些系統可以直接保留

- **世界與地形**：格子碰撞、地形速度、高度、區域、尋路、雲霧——即時戰鬥的移動、投射物撞牆、追擊與逃跑都直接用它們。
- **玩家移動**：`step()` 的搖桿／WASD 移動、碰撞滑行、地形速度、境界加速，戰鬥中照用。
- **野獸的「知覺」**：在領域閒晃、聽見、警戒「？」、追擊「！」、晝夜習性（狼夜裡更兇、正午打盹）、遠強於牠就逃——即時 AI 的前半段（發現→警戒→追擊）就是它。
- **數值模型**：戰力、`fightPower`、「強弱相對」的血量／傷害推算、各種敵人的形狀（皮厚、兇猛、快）、戰利品、修為與系統經驗的獎勵、險勝留傷。
- **資料**：`FOES`、`MOBS`、`ITEMS`、技能名稱與效果（灼燒、中毒、暈、護盾、回血）。
- **畫面**：兩種畫法、立牌、人物與妖獸的繪製（含新畫的大型妖獸）、受擊閃紅、傷害數字、狀態標記、血條。
- **事件、敘事、NPC、修煉、存檔**：完全不動。

### B. 哪些系統需要重構

| 系統 | 現在 | 改成 |
|---|---|---|
| 戰鬥迴圈 | `act()` 一次結算整輪 | 每幀推進的戰鬥模擬（和移動同一個 `step`） |
| 戰鬥入口 | 野獸碰到你 → 開事件卡 → 選「迎戰」→ 戰鬥面板 | 野獸發現你 → 就地進入戰鬥狀態，世界不停 |
| 敵人 AI | 只會追、碰到就開事件 | 追擊、保持距離、蓄勢（地面預警）、撲擊、撤退、放棄追擊 |
| 技能 | 回合冷卻、點選對象 | 秒數冷卻、施法時間、方向／距離／範圍（直線、投射物、圓形、自身） |
| HP／靈力 | 戰鬥開始才算出來 | 跟著角色走：戰鬥外慢慢回復，傷勢壓低上限 |
| 時間 | 走路就過時辰 | 戰鬥中移動不再快轉時間（改用很慢的戰鬥時間） |
| 介面 | 回合制面板 | 左搖桿、右側技能鍵（冷卻、靈力、拖曳瞄準），上方 HP／靈力，敵人頭上名稱、境界、血條；PC：WASD、滑鼠瞄準、數字鍵、空白鍵 |
| 畫面 | 播放一拍一拍的結果 | 即時：角色的揮砍、施法、閃避姿勢，飛行的劍氣與火球，爆炸，地面預警與瞄準範圍 |

### C. 回合制的哪些部分可以轉成即時

- **出手順序（身法）→ 攻速與移速**：身法高的人攻擊間隔短、走得快、閃避冷卻短。
- **閃避機率 → 真的閃**：不再擲骰「閃」，而是蓄勢時看得見的預警，玩家走出範圍或用閃避的無敵時間躲開。
- **防禦 → 護體技能**：減傷／吸收傷害的護盾，有持續時間與冷卻。
- **後退 → 移動與閃避**：自己拉開距離。
- **逃跑機率 → 真的跑**：見 G。
- **技能**：名稱、靈力消耗、倍率、屬性（劍氣、火、靈）、附帶效果（灼燒、中毒、暈）全部沿用；「冷卻 n 回合」改成「冷卻 n 秒」，「點選對象」改成各自的施法方式。
- **敵人的技能**：撲擊→帶預警的突進；撕咬→近身扇形；纏絞→定身；毒霧→範圍；劍氣→直線飛行物；狐火→追蹤火；閃身→位移閃避；狼王嘯→狂暴階段。
- **數值**：血量與傷害沿用「強弱相對」的推算，只是把「幾下打死」從回合數改成合理的即時節奏（勢均力敵的一場約 20–40 秒）。
- **勝負後果**：修為、戰利品、系統經驗、險勝帶傷、輸了的後果，全部沿用。

### D. 玩家移動能不能直接和戰鬥整合

可以，而且這是最大的好處。戰鬥不另開場景：**戰鬥中跑的仍是同一個 `step()`、同一個角色位置 `s.world.x/y`、同一套碰撞與地形速度**。戰鬥只在上面加幾件事：

- 施法時移動變慢、閃避時短暫高速位移（有無敵時間）、被擊中時被擊退。
- 戰鬥中移動不再觸發隨機遭遇、區域事件，也不讓時間快轉。
- 點地面仍然是「走過去」；點敵人變成「鎖定並攻擊」（太遠就自動靠近）。

### E. 技能怎麼改成即時施放

每個技能是一筆資料：

```
{ id, name, slot, mp, cd(秒), cast(施法秒數), aim: 'melee'|'line'|'ground'|'self'|'target', range, width/radius, speed(飛行速度), mult(倍率), kind(phys/spirit/fire), 附帶效果 }
```

- **按一下**：立即施放，自動瞄準鎖定的敵人（沒有就最近的敵人，再沒有就面朝的方向）。
- **按住拖曳**（手機）：地面出現範圍預覽（直線、落點圓），放開才施放；拖回按鈕中央取消。
- **PC**：數字鍵朝滑鼠游標的方向／位置施放；滑鼠移動時就看得到預覽。
- 施放後進入冷卻（按鈕上的扇形倒數），扣靈力；投射物在世界裡飛行、撞到敵人或地形才結算，範圍技能落地時判定範圍內所有敵人。
- 施法方式先做四種：**近身扇形（普攻）、直線飛行（劍氣）、投射物＋落點爆炸（火球）、自身（護體）**；之後再加扇形（劍陣）、指定目標（雷法）、持續區域（陣法）等。

### F. 敵人 AI 怎麼改成即時追擊／攻擊

每隻敵人一個狀態機，每幀更新：

```
閒晃 → 察覺（看見你，頭上「？」）→ 警戒（盯著你，半秒）→ 追擊（「！」）
     → 進入攻擊距離 → 蓄勢（地面出現紅色預警）→ 出手（判定當下你在不在範圍裡）
     → 硬直（攻擊後的空檔，你的反擊時機）→ 重新選擇：再追、繞、撤退
     → 追丟或離家太遠 → 放棄（回到領域、慢慢回血）
```

- **攻擊一定有預警**：蓄勢時間（0.3–0.8 秒）讓玩家看得見、躲得開；攻擊後有硬直，形成「找空檔」的節奏。
- **打法由資料決定**：近戰型（貼身咬）、遠程型（保持距離放飛行物）、高速型（衝上來咬一口就跳開）、坦克型（慢、皮厚、重擊）、法修（遠距離施法）、劫修（偷襲後看情況追或逃）。
- 第一階段只做一種：**妖狼（高速型近戰）**——追擊、撕咬（短預警扇形）、撲擊（長預警直線突進）、咬完跳開、半血時長嚎狂暴。

### G. 逃跑／脫離戰鬥怎麼設計

沒有「逃跑」按鈕。逃跑就是**真的跑**：

- 每隻敵人有**追擊範圍**：你離牠太遠（看不見你）一段時間，或牠離自己的領域太遠，牠就放棄，回家去。所有敵人都放棄 → 「已脫離戰鬥」。
- **速度**：妖狼比剛入煉氣的你快一點，直線跑不掉；要靠閃避躲掉撲擊、利用牠攻擊後的硬直拉開距離。境界越高跑得越快。
- **地形**：密林讓大型妖獸跑得更慢、更快追丟你；妖獸不進城鎮，跑進城就安全。
- **強弱**：高階妖獸追得更遠、更快；之後的飛行法器、遁術、位移技能都會讓逃跑更容易。
- 逃走了，野獸還在原處；回來可以再打一次（牠會回血）。

### H. 怎麼避免戰鬥和世界地圖變成兩個系統

- **同一個世界**：敵人就是地圖上那隻野獸本身（同一個物件、同一組座標），不是另外複製到戰鬥場景的替身。
- **同一個迴圈**：探索與戰鬥都在 `step()` 裡；「戰鬥狀態」只是一個旗標，改變的是輸入對應、HUD 與規則（時間、事件暫緩），不切畫面、不暫停世界。
- **同一個鏡頭與畫法**：鏡頭仍跟著你，只稍微拉近；戰鬥特效畫在原本的世界上（地面預警直接畫進地形裡）。
- **同一套結果**：勝負的後果（修為、戰利品、傷勢）走原本的效果系統；之後故事裡的戰鬥也會改成「在現場的那些人直接動手」，打完把勝／敗／逃交回事件，接上原本的結局文字。

## 三、新架構

```
                ┌──────────── 每一幀 step(s, dt, 輸入) ────────────┐
                │                                                  │
   探索狀態 ────┤  移動（同一套碰撞與地形） ← 搖桿／WASD／點地      │
     ▲          │  野獸的知覺與 AI（同一批野獸）                    │
     │          │  戰鬥模擬：普攻、技能、飛行物、範圍、冷卻、靈力、 │
     │          │            閃避、護體、受擊、擊退、狀態            │
   脫離／勝負   │  事件與時間（戰鬥中暫緩）                          │
     │          └──────────────────────────────────────────────────┘
     ▼
   戰鬥狀態（旗標）：HUD 與按鍵換成戰鬥用，鏡頭微微拉近
```

| 模組 | 內容 |
|---|---|
| `world/combat.js`（新） | 即時戰鬥：戰鬥狀態、玩家的 HP／靈力／冷卻、普攻與技能、飛行物、範圍判定、閃避、護體、受擊、境界壓制、妖獸 AI、脫離戰鬥、勝負與後果。純邏輯，可用 `node --test` 測。 |
| `content/moves.js`（新） | 即時技能與妖獸招式的資料（施法方式、距離、冷卻、倍率）。 |
| `content/foes.js` | 敵人加上即時用的數值：速度、視野、追擊範圍、階級（境界）。 |
| `world/places.js` | `BEASTS`：即時妖獸在地圖上的位置與領域。 |
| `world/explore.js` | `step()` 接上戰鬥：戰鬥中不觸發事件、不快轉時間。 |
| `art/combatfx.js`（新） | 兩種畫面共用：角色的戰鬥姿勢、妖獸蓄勢與撲擊、飛行物、爆炸、地面預警與瞄準預覽、血條、傷害數字。 |
| `art/gl/`（地形） | 地面標記貼圖：預警與瞄準範圍畫在地上、人在它上面。 |
| `ui/app.js` | 戰鬥 HUD 與操作：左搖桿、右側技能鍵、拖曳瞄準、PC 鍵鼠。 |

回合制引擎（`core/battle.js`）暫時保留給故事裡的戰鬥，直到第三階段把它們也搬成即時。

## 四、分階段計畫

| 階段 | 內容 |
|---|---|
| **一：即時戰鬥原型（本次）** | 玩家＋一隻妖獸（妖狼）。自由移動、普攻、三個技能（劍氣、火球、護體）、閃避、HP／靈力、冷卻、妖獸 AI（追擊、撕咬、撲擊、撤退、狂暴）、地面預警與瞄準預覽、逃跑／脫離戰鬥、境界壓制、勝負後果。問道系統另有「戰鬥試煉」，隨時在身邊幻化一隻妖狼來練手。 |
| 二：野外的妖獸都改成即時 | 狼群（圍攻）、青鱗蛇（毒）、殘魂（遠程、怕法術）、山賊與劫修（偷襲、看情況追或逃）；更多技能與功法對應；精英妖獸。 |
| 三：故事裡的戰鬥改成即時 | 23 場戰鬥：現場的人直接動手，幫手並肩作戰，切磋點到為止；勝／敗／逃接回原本的結局。之後回合制引擎退役。 |
| 四：Boss | 大型妖獸（例如赤炎妖虎）：多段招式、範圍技、突進、血量階段、狂暴；秘境 Boss。 |
| 五：流派 | 劍修（劍氣、劍影、飛劍、劍陣）、法修（五行法術、大範圍法術）、體修（突進、護體、爆發）、符籙、傀儡、毒術、陣法、御獸。 |
| 六：與飛行、天時、勢力結合 | 御劍逃跑、空中追擊、天氣影響法術、宗門修士巡邏。 |

## 五、第一階段原型的規格

**操作**

| | 手機 | PC |
|---|---|---|
| 移動 | 左邊拖動（搖桿） | W A S D |
| 普攻 | 右下大鈕（按住連續攻擊）；點敵人＝鎖定並攻擊 | J 或滑鼠左鍵 |
| 技能 | 右下三顆：按一下自動瞄準；按住拖曳＝手動瞄準，放開施放 | 1 2 3（朝滑鼠方向） |
| 閃避 | 右下「閃」 | 空白鍵（朝移動方向；沒在動就朝滑鼠） |

**技能（煉氣以上人人都會，學過相關功法會更強）**

| 技能 | 施法方式 | 靈力 | 冷卻 | 說明 |
|---|---|---|---|---|
| 普攻 | 近身扇形（弓：飛箭） | — | 依兵器 0.45–0.8 秒 | 拳腳、柴刀、青鋼劍、獵弓各有手感 |
| 劍氣 | 直線飛行，穿透 | 6 | 3 秒 | 學過青元劍訣／青雲心法更強、更遠 |
| 火球 | 飛向落點，爆炸範圍傷害＋灼燒 | 8 | 5 秒 | 學過烈焰訣更強 |

**妖狼（一階妖獸）**：比剛入煉氣的你快；撕咬（短預警）、撲擊（長預警的直線突進，傷害高）、咬完跳開；半血長嚎狂暴。打贏得狼皮、可能得妖獸內丹與修為；被打倒會受傷、昏過去一陣子。凡人遇上牠是境界壓制：傷不了牠多少，只能跑。
